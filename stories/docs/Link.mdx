## Accessibility

- Renders a native `<a>` element — keyboard focusable and activatable via `Enter` by default
- When `disabled` is true, `href` is removed and `aria-disabled="true"` is set so screen readers announce the state while the element remains in the tab order
- The decorative arrow `▶` carries `aria-hidden="true"` so screen readers only announce the label text
- When `target="_blank"`, `rel="noopener noreferrer"` is applied automatically to prevent tab-napping
