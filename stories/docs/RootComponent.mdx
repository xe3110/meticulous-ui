# RootComponent

`RootComponent` is the required wrapper for any app or subtree that uses meticulous-ui. It sets `font-size: 62.5%` on its container so that `1rem = 10px`, which is the sizing baseline all meticulous-ui components are built on.

Wrap your entire app — or at minimum the subtree where meticulous-ui components appear — with `RootComponent` once, at the top level.

```jsx
import RootComponent from 'meticulous-ui/components/RootComponent';

const App = () => <RootComponent>{/* rest of your app */}</RootComponent>;
```

## Notes

- Place `RootComponent` **once** at the top of your component tree, not around individual components.
- If your host app already sets `font-size: 62.5%` on `html` or `body`, you can omit `RootComponent` — but wrapping a subtree is harmless.
- The underlying element is a plain `<div>`, so layout props like `style` or `className` can be passed through to control its box behaviour.
