## Accessibility

- Renders with `role="status"` so screen readers announce the loading state as a polite live region
- A visually-hidden label (e.g. `"Loading…"`) should be provided by the consuming component when no other visible loading label is present
- The spin animation is suppressed for users with `prefers-reduced-motion: reduce`
