## Accessibility

- The pagination component renders inside a `<nav>` element with `aria-label="Pagination"` so screen readers identify it as a navigation landmark
- Each page button is a native `<button>` element; the active page button has `aria-current="page"`
- Previous / next arrow buttons have descriptive `aria-label` attributes
- When `isDisabled` is true, all buttons receive the native `disabled` attribute
