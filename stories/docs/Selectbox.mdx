# Selectbox

A multi-select dropdown where each option has a checkbox. The trigger shows how many items are selected. Can be imported as `meticulous-ui/components/Selectbox`.

Options are passed as an array of `{ label, value, disabled? }` objects.

## Accessibility

- The trigger uses `role="button"` — keyboard focusable and openable via `Enter`, `Space`, `ArrowDown`, or `ArrowUp`
- The menu uses `role="listbox"` with `aria-multiselectable="true"` and each option as `role="option"` with `aria-selected`
- Disabled options receive `aria-disabled="true"` and are skipped by arrow-key navigation
- `isDisabled` sets `aria-disabled="true"` on the trigger and blocks all interaction
- `aria-activedescendant` tracks the keyboard-highlighted option for screen readers
- `Escape` closes the menu; focus returns to the trigger
