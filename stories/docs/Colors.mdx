# Colors

The full color palette used across meticulous-ui. Each color family is available as a named import from `meticulous-ui/colors/<name>` and exposes shades from `m100` (lightest) to `m900` (darkest).

```jsx
import blue from 'meticulous-ui/colors/blue';

blue.m500; // → '#2196f3'
```

## Accessibility

- Ensure sufficient contrast between text and background colors — aim for at least **4.5 : 1** for normal text (WCAG AA)
- Shades `m600` and above on white backgrounds, and `m400` and below on dark backgrounds, generally meet AA contrast requirements
- Never rely on color alone to convey meaning — pair with text labels, icons, or patterns
