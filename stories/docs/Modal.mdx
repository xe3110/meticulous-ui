# Modal

A Modal renders in a portal over the page. It can be imported as `meticulous-ui/components/Modal`.

Supports an optional title, body content, footer, keyboard dismissal (`Esc`), and overlay click to close.

## Accessibility

- Renders with `role="dialog"` and `aria-modal="true"` so screen readers announce it as a dialog
- The overlay receives `aria-label` from the `title` prop when provided
- `Esc` always calls `onClose` while the modal is open
- Body scroll is locked (`overflow: hidden`) while the modal is open and restored on close
- The close button has `aria-label="Close modal"` for screen reader support
