# Modal

A Modal renders in a portal over the page. It can be imported as `meticulous-ui/components/Modal`.

Supports an optional title (string or React element), body content, footer, keyboard dismissal (`Esc`), overlay click to close, animated open/close transitions, and a mobile bottom-sheet mode.

## Custom Title Component

The `title` prop accepts any React element. Strings are wrapped in the default heading style; elements are rendered as-is inside an `aria-labelledby` target, so screen readers still announce the dialog title correctly.

## Scrollable Content

## Full On Mobile

When `isFullOnMobile` is set, the modal fills the screen width on viewports ≤ 640 px and slides up from the bottom with a spring animation. Closing reverses the animation before unmounting. On desktop it behaves as a normal centered modal.

## Accessibility

- `role="dialog"` and `aria-modal="true"` are on the modal container (not the backdrop), so screen readers correctly announce it as a dialog and hide background content
- When a `title` is provided the dialog is labelled via `aria-labelledby`, which works for both string and React element titles
- Focus moves to the first focusable element inside the modal on open, and is trapped there — Tab and Shift+Tab cycle only within the modal
- On close, focus is restored to the element that originally triggered the modal
- `Esc` always calls `onClose` while the modal is open
- Body scroll is locked (`overflow: hidden`) while open and restored on close
- The ✕ button has `aria-label="Close modal"` and the SVG icon carries `aria-hidden="true"`
