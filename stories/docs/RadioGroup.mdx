# RadioGroup

A group of radio buttons for single-option selection from a list. Can be imported as `meticulous-ui/components/Input/RadioGroup`.

Options are passed as an array of `{ label, value, disabled? }` objects.

## Accessibility

- Renders native `<input type="radio">` elements grouped inside a `<fieldset>` / `role="radiogroup"` so screen readers announce the group
- Each option's `label` is associated via a `<label>` element
- Disabled options receive the native `disabled` attribute
- Arrow keys navigate between options within the group per the WAI-ARIA radio group pattern
