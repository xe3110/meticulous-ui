# Shimmer

A skeleton loading placeholder that communicates content is on its way. Use it in place of text, images, or cards while data is being fetched. Can be imported as `meticulous-ui/components/Shimmer`.

## Default

## Custom Border Radius

Use the `borderRadius` prop to match the shimmer shape to your content — square for images, pill for tags, or circular for avatars. Numbers are treated as rem values.

## Accessibility

- Renders with `role="status"` so screen readers announce the loading state as a polite live region
- `aria-label` defaults to `"Loading..."` and can be overridden via the `label` prop for context-specific descriptions
- The sweep animation is purely decorative and conveys no meaning beyond a loading state
