## Accessibility

- All custom controls (play, mute, seek, volume, fullscreen) are `<button>` elements with `aria-label` attributes
- The underlying `<video>` element supports native browser accessibility — keyboard-navigable via the player controls
- The keyboard shortcut layer listens on the player container so focus does not need to be on a specific button
- For full accessibility, provide captions/subtitles via `<track>` elements in the video source; the component exposes the native `<video>` slot for this
