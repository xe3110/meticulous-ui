# Timer

A countdown timer that supports both an analog (circular arc) and a digital (numeric) display mode. Can be imported as `meticulous-ui/components/Timer`.

The preview below shows a digital timer (top) and an analog timer (bottom) running simultaneously.

## Accessibility

- Control buttons (play, pause, remove, add) render as native `<button>` elements with `aria-label` attributes describing their action
- The remaining time is rendered in a `<time>` element with a human-readable `datetime` attribute so screen readers can announce it
- Color alone is not used to communicate state — the digital countdown value or arc position conveys progress independently of color
