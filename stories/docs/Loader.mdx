# Loader

A Loader displays five dots in a sequential wave-bounce animation to communicate a loading state. Can be imported as `meticulous-ui/components/Loader`.

The dots transition in color from **mint green → teal → cyan → sky blue → deep blue** and increase progressively in size from left to right.

## Accessibility

- The wrapper has `role="status"` — an implicit `aria-live="polite"` live region
- A visually-hidden `"Loading"` text node is announced by screen readers when the component mounts
- Each decorative dot has `aria-hidden="true"` to keep the accessibility tree clean
- Animations are suppressed for users with `prefers-reduced-motion: reduce`
