# Icons

A collection of SVG icon components. Each icon is individually importable from `meticulous-ui/components/Icons/<Name>` (e.g. `meticulous-ui/components/Icons/Add`).

## All Icons

<Canvas of={IconStories.Default} />

## Usage

```jsx
import Add from 'meticulous-ui/components/Icons/Add';
import red from 'meticulous-ui/colors/red';

<Add color={red.m500} size={20} />
```

## Accessibility

- Icons render as `<svg>` elements
- When used as decorative elements alongside visible text, add `aria-hidden="true"` to remove them from the accessibility tree
- When used as standalone interactive icons (e.g. inside an icon-only button), the parent `<button>` must have an `aria-label` describing the action
- Avoid relying on color alone to convey meaning — pair with a visible label or tooltip when the icon is the sole indicator
