# Carousel

Maps over a `data` array and renders each item using a `renderCarousel` render prop. The component owns the slide track, chevron navigation, and dot indicators — you own the slide content. Can be imported as `meticulous-ui/components/Carousel`.

## Image Carousel

Single slide visible at a time. Chevrons disable automatically at the first and last slide.

<Canvas of={CarouselStories.ImageCarousel} />

## Card Carousel (2 visible)

Pass `visibleSlides={2}` to show two slides side-by-side. The active dot follows the leading slide. Use padding inside each rendered item to add gutters between cards.

## Testimonial Carousel

Single-slide quotes with dot navigation. Clicking a dot jumps directly to that slide.

<Canvas of={CarouselStories.TestimonialCarousel} />

## Overlay Arrows

Pass `overlayArrows` to render the chevrons inside the slide area. They fade out after 2 seconds and reappear on hover, tap, or click.

<Canvas of={CarouselStories.OverlayArrows} />

## Arrow Position

Use `arrowTop` to pin the overlay chevrons to a specific vertical position. Accepts any CSS string (`"20%"`, `"80px"`) or a number (treated as px). Defaults to `"50%"`.

<Canvas of={CarouselStories.ArrowPosition} />

## Auto Slide

Pass `autoSlide` to advance slides automatically. A pause/play button appears in the bottom-right corner of the slide area. `showProgress` adds a thin progress bar that fills over `autoSlideSec` seconds and resets on each advance. Auto-play pauses on hover and keyboard focus.

<Canvas of={CarouselStories.AutoSlide} />

## Hidden Dots

Pass `areDotsHidden` to remove the dot indicators — useful when slide position is conveyed another way or a minimal look is preferred.

<Canvas of={CarouselStories.HiddenDots} />

## Loop

Pass `loop` to enable infinite navigation. Pressing next on the last slide wraps back to the first, and prev on the first wraps to the last. Both chevrons stay enabled at all times — the disabled state only applies when `loop` is off.

<Canvas of={CarouselStories.Loop} />

## Drag to Slide

Pass `dragToSlide` to enable mouse-drag navigation on the slide area. The cursor changes to a grab hand and the same distance threshold used for touch swipe applies. Set `pointerEvents: none` on images inside `renderCarousel` to prevent the browser's native image-drag from interfering.

<Canvas of={CarouselStories.DragToSlide} />

## Live Drag

Pass `liveDrag` to make the slide track follow the pointer in real-time. On release it either snaps forward or bounces back using the standard transition. At the first and last slide (when `loop` is off), 30% resistance is applied for an iOS rubber-band feel. Works on both touch and mouse — pair with `dragToSlide` to also enable mouse drag.

<Canvas of={CarouselStories.LiveDrag} />

## External Control

Use `defaultIndex` to set the initial active slide without controlling it, and `onSlideChange` to receive the current zero-based index on every navigation event — chevrons, dots, drag, swipe, and keyboard all fire it. Combine these to sync an external caption, fire analytics, or reflect the slide in a URL param.

## Usage notes

- Wrap each rendered item's content in a `div` with `padding: '0 8px'` to create gutters without breaking the flex layout.
- The left chevron is disabled at index 0 and the right at `data.length - visibleSlides`, unless `loop` is true.
- Dots represent each valid starting position. The active dot expands to a pill shape to indicate the current slide.
- `arrowTop` only has an effect when `overlayArrows` is also set.
- `autoSlideSec` and `showProgress` only have an effect when `autoSlide` is also set.
- `prefers-reduced-motion` disables the slide transition animation and the progress bar fill animation automatically — no prop needed.
- Set `pointerEvents: none` on images inside `renderCarousel` when using `dragToSlide` to prevent the browser's native image-drag from conflicting.
