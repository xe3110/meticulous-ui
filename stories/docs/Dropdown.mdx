# Dropdown

A single-select dropdown with optional search, infinite scroll, and theming. Can be imported as `meticulous-ui/components/Dropdown`.

Options are passed as an array of `{ label, value, disabled? }` objects.

## Accessibility

- The trigger renders as a `<button>` — keyboard focusable and openable via `Enter` / `Space`
- The menu uses `role="listbox"` with each option as `role="option"` and `aria-selected`
- Disabled options receive `aria-disabled="true"`
- `isDisabled` sets `aria-disabled="true"` and `disabled` on the trigger button
- `isLoading` should be paired with `aria-busy="true"` on the trigger by consuming code when options are not yet available
