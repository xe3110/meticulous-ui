# Image

Renders an image with a shimmer placeholder shown while the image loads. Once loaded, the image fades in smoothly. Can be imported as `meticulous-ui/components/Image`.

## Default

<Canvas of={ImageStories.Default} />

<Controls of={ImageStories.Default} />

## Rounded

Pass `borderRadius='50%'` for circular images — useful for avatars or profile photos.

<Canvas of={ImageStories.Rounded} />

## Load Low

Pass `loadLow` and `lowSrc` to show a blurred low-resolution placeholder while the full image fetches — shimmer appears first, then the blurred preview, then the full image.

<Canvas of={ImageStories.LoadLow} />

## Accessibility

- Always provide a meaningful `alt` prop — screen readers announce it when the image loads
- The shimmer placeholder underneath uses `role="status"` and `aria-label="Loading..."` (inherited from the `Shimmer` component) to announce the loading state
