# OtpInput

A one-time password input that renders a row of single-character boxes. Automatically advances focus between boxes as the user types. Can be imported as `meticulous-ui/components/OtpInput`.

## Accessibility

- Each box is a native `<input type="text" inputmode="numeric">` element, keyboard accessible by default
- Focus moves automatically to the next box on input and back on `Backspace`, reducing navigation effort
- The group should be wrapped in a `<fieldset>` with a `<legend>` (e.g. "Enter OTP") by the consuming layout so screen readers announce the purpose
- Paste support fills all boxes from the clipboard value in a single operation
