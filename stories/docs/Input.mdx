## Accessibility

- Renders a native `<input>` element; the `label` prop is wired via `htmlFor` / `id` so screen readers announce the field name
- `helperText` is associated with the input via `aria-describedby` so assistive technology reads it after the field name
- When `hasError` is true, `aria-invalid="true"` is set on the input
- `disabled` maps to the native `disabled` attribute, removing the field from the tab order
