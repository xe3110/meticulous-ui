# Switch

A toggle switch that reports `true` / `false` via `onChange`. Renders as a semantic `<button role="switch">`. Supports optional icons in the thumb and per-state colours and labels rendered inside the track.

Import as `meticulous-ui/components/Switch`.

## With Labels

A frosted-glass thumb variant designed for use on dark or coloured backgrounds. Enable with `isGlass`. Pair with `onIcon` / `offIcon` for a glowing icon effect inside the glass.

## Accessibility

- Renders a native `<button>` with `role="switch"` and `aria-checked` — keyboard focusable and togglable via `Space` or `Enter` by default
- `aria-checked` reflects the current boolean state so screen readers announce _"on"_ or _"off"_ automatically
- When no visible label is present, pass `label` to set `aria-label`, or use `id` with an external `<label htmlFor>`
- The thumb and all decorative glass layers carry `aria-hidden="true"` so assistive technology only reads the button's accessible name and state
- Both native `disabled` and `aria-disabled` are set when disabled
