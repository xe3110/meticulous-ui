# Toast

Displays brief, non-blocking notifications at the edge of the screen. Four types are supported: `success`, `info`, `warning`, and `error`. Can be imported as `meticulous-ui/components/Toast`.

Click the buttons in the preview below to trigger each toast type.

## Accessibility

- The container renders with `role="region"` and `aria-live="polite"` so new toasts are announced by screen readers without interrupting the user
- Each toast has `role="alert"` for urgent `error` / `warning` types (assertive) and `role="status"` for `success` / `info` (polite)
- Dismiss buttons have a descriptive `aria-label` so screen readers can identify them
- Toasts auto-dismiss after a timeout; keyboard users can also dismiss manually via the close button
