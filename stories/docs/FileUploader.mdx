# FileUploader

A styled file-input button that triggers the browser's file picker. Supports theming, sizing, icons, multiple file selection, and accepted file type filtering. Can be imported as `meticulous-ui/components/Input/FileUploader`.

## Accessibility

- The visible styled button is a `<label>` wrapping a visually-hidden `<input type="file">`, so activating the button via keyboard (`Enter` / `Space`) opens the file picker
- `disabled` sets the native `disabled` attribute on the underlying input and applies visual muting to the label
- The `label` text is part of the clickable label element, so screen readers announce it when the input is focused
- When `isMultiple` is true the input receives `multiple`, and the label should reflect this (e.g. "Upload Files") so the intent is clear to screen reader users
