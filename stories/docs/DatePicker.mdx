# DatePicker

A calendar picker supporting both single-date and date-range selection. Can be imported as `meticulous-ui/components/DatePicker`.

Includes an inline month/year navigator, a hover-preview range band, and an optional footer with Clear / Apply actions.

## Min / Max Dates

Use `minDate` and `maxDate` to restrict which dates are selectable. Dates outside the window are rendered dimmed and cannot be clicked.

<Canvas of={DatePickerStories.MinMaxDates} />

## No Footer

`showFooter={false}` removes the Clear / Apply row and fires `onChange` immediately on each click — useful when embedding the picker inline without a confirmation step.

<Canvas of={DatePickerStories.NoFooter} />

## No Mode Toggle

`showModeToggle={false}` hides the Single / Range pill. Combine with a fixed `mode` prop to lock the picker into one behaviour.

## Accessibility

- All interactive elements render as native `<button>` elements — fully keyboard focusable and activatable via `Enter` / `Space`
- Navigation arrows carry `aria-label="Previous month"` / `"Next month"`
- Each day button has `aria-label` set to the full date string (e.g. `"Thu May 01 2025"`) and `aria-pressed` reflecting the selected state
- Disabled days receive the native `disabled` attribute and are removed from the tab order (`tabIndex={-1}`)
- Focus outlines use the active theme color and are visible on `:focus-visible` for keyboard-only navigation
