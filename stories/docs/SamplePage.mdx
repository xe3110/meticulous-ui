# SamplePage — Axion Analytics Landing Page

A production-style interactive landing page built entirely from meticulous-ui primitives. It serves as a live reference for how components, hooks, utilities, icons, and color tokens compose into a real application.

`RootComponent` is mounted **inside** the page component itself — no external wrapper is required in the story.

## Key patterns

### Self-contained RootComponent

The page wraps its own `<RootComponent>` so consumers can drop it in without any extra wrapper:

```jsx
const LandingPage = () => {
  // ...state...
  return (
    <RootComponent>
      <Page>{/* sections */}</Page>
    </RootComponent>
  );
};
```

### Dark mode with useLocalStorage

Dark-mode preference survives page reloads:

```jsx
const [isDark, setIsDark] = useLocalStorage('axion-dark', false);
```

The `dk()` helper threads the `$dark` prop through styled-components without prop drilling:

```js
const dk =
  (dark, light) =>
  ({ $dark }) =>
    $dark ? dark : light;

const Card = styled.div`
  background: ${dk(blueGray.m800, white)};
  border: 1px solid ${dk(blueGray.m700, blueGray.m100)};
`;
```

### Toast self-cleanup

Each toast carries its own `onExpire` so no external `setToasts` prop is needed on `ToastContainer`:

```jsx
const pushToast = (type, title, subtitle) => {
  const id = `${type}-${Math.random().toString(16).slice(2)}`;
  setToasts((prev) => [
    ...prev,
    {
      id,
      type,
      title,
      subtitle,
      onExpire: () => setToasts((p) => p.filter((t) => t.id !== id)),
    },
  ]);
};
```

### Modal scroll-chain guard

A `<div onWheel>` wrapper prevents the Storybook canvas from scrolling when the modal or its `Dropdown` captures wheel events:

```jsx
<div onWheel={(e) => e.stopPropagation()}>
  <Modal isOpen={open} onClose={close} title="Book a live demo">
    <Dropdown menuHeight="16rem" {/* bounded list — its own scroll container */} />
  </Modal>
</div>
```

### Pricing layout stability

The "Save up to 26%" line uses `visibility` instead of conditional rendering so the layout never shifts when toggling between monthly and annual billing:

```jsx
<span
  style={{
    visibility: isAnnual ? 'visible' : 'hidden',
    minHeight: '1.8rem',
  }}
>
  ✓ Save up to 26% with annual billing
</span>
```

### FAQ accordion

The FAQ section uses `allowMultiple` so users can read several answers side-by-side. `activeBackground` is dark-mode aware — it switches between `indigo.m50` (light) and `blueGray.m800` (dark). Each item carries its own `iconColor` to visually distinguish categories:

```jsx
<Accordion items={FAQ_ITEMS} allowMultiple activeBackground={isDark ? blueGray.m800 : indigo.m50} />
```

```js
const FAQ_ITEMS = [
  {
    id: 'billing',
    title: 'How does billing work?',
    icon: <PaymentCardFilled />,
    iconColor: teal.m600,
    content: 'You are billed monthly or annually…',
  },
  // …
];
```

### Shimmer → content reveal

`useTimeout` drives a one-shot flag that swaps skeleton cards for real content:

```jsx
const [featuresLoaded, setFeaturesLoaded] = useState(false);
useTimeout(() => setFeaturesLoaded(true), 1400);

// In JSX:
{
  featuresLoaded ? (
    <FeatureCard />
  ) : (
    <Card>
      <Shimmer width='100%' height='2rem' />
    </Card>
  );
}
```
