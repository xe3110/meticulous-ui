# Accordion

An Accordion renders a list of collapsible panels. Each panel has a header that toggles its body open or closed. It can be imported as `meticulous-ui/components/Accordion`.

Supports optional per-item icons with configurable colors, an active-panel background, keyboard navigation, and a mode that allows multiple panels open simultaneously.

## Icon Color

Set a default icon color for all items via the `iconColor` prop on the Accordion. Any item can override it with its own `iconColor` field — item-level always wins.

<Canvas of={AccordionStories.IconColorOverride} />

## Item Background

`itemBackground` controls the resting (closed) item background. It defaults to `#fff` — pass any palette token to match your page background.

<Canvas of={AccordionStories.ItemBackground} />

## Active Background

Pass any color token from the palette via `activeBackground` to tint the expanded item. The border is hidden when a background is active so the color reads cleanly.

<Canvas of={AccordionStories.ActiveBackground} />

## Rich Content (JSX title & content)

Both `title` and `content` accept any `ReactNode` — pass plain strings for simple cases or full JSX trees for badges, code blocks, tables, or any other component.

## Accessibility

- Each header renders as a native `<button>` — keyboard focusable and activatable via `Enter` / `Space`
- `aria-expanded` on the header reflects the open state for screen readers
- The body panel uses `role="region"` with `aria-labelledby` pointing back to its header
- `focus-visible` outline is applied on keyboard navigation without affecting mouse users
