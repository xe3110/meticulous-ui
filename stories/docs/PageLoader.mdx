# PageLoader

A full-page loading indicator used to block the UI while async operations are in progress. Can be imported as `meticulous-ui/components/PageLoader`.

## Accessibility

- Should be rendered with `role="status"` and `aria-label="Loading"` so screen readers announce the loading state
- The consuming page should ensure interactive elements are inert or hidden behind the loader while it is visible
- The animation should respect `prefers-reduced-motion: reduce`
