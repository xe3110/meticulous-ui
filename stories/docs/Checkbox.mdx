## Accessibility

- Renders a native `<input type="checkbox">` element, fully keyboard accessible via `Space` to toggle
- The `label` prop is associated via `<label>` wrapping or `htmlFor`, so screen readers announce the field name
- When `disabled` is true the native `disabled` attribute is set, removing the element from the tab order
- Checked/unchecked state is communicated natively via the `checked` attribute
