## Accessibility

- All components render their native HTML semantic elements (`<h1>`–`<h6>`, `<p>`), preserving the document outline for screen readers and SEO
- Heading levels should be used in hierarchical order within a page — do not skip levels for visual sizing purposes; use the `size` / `color` props instead
- Color alone is not used to convey meaning; combine with other visual cues when needed
