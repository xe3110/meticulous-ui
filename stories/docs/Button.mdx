# Button

A Button triggers an action or event. It can be imported as `meticulous-ui/components/Button`.

Supports multiple themes, sizes, a loading state (renders an inline spinner), and a disabled state.

## Accessibility

- Renders a native `<button>` element — keyboard focusable and activatable via `Enter` / `Space` by default
- When `disabled` is true the button receives the native `disabled` attribute, removing it from the tab order and preventing click events
- When `isLoading` is true, consider pairing with an `aria-label` or `aria-busy` attribute on the wrapping context so screen readers can announce the pending state
